1. Описание проекта. Данный проект представляет собой веб-сервер, который реализует функциональность планировщика задач.
При запуске сервера можно в браузере открыть заранее подготовленный (имеется фронтенд), но доработанный в ходе выполнения проекта планировщик задач, который позволяет выбиирать дни недели,
месяца и года,и в конкретные дни добавлять задачи, устанавливать повторность оповещения о выполнении задач (наподобие ежедневника или заметок в телефоне).

2. Код запускается после скачивания проекта на компьютер путем запуска в терминале текстового редактора (VS Code в мое случае) сервера командой go run main.go. Ардрес в браузере при после запуска сервера указывается как http://localhost:7540
tests/settings.go использует параметры:
    
      package tests

        var Port = 7540
        var DBFile = "../scheduler.db"
