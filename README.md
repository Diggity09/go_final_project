# Веб-планировщик задач
## Описание:
Создан полнофункциональный веб-сервер для управления задачами с возможностью создания, редактирования и отслеживания статуса. Данный проект представляет собой веб-сервер, который реализует функциональность планировщика задач.
При запуске сервера можно в браузере открыть заранее подготовленный (имеется фронтенд), но доработанный в ходе выполнения проекта планировщик задач, который позволяет выбиирать дни недели,
месяца и года,и в конкретные дни добавлять задачи, устанавливать повторность оповещения о выполнении задач (наподобие ежедневника или заметок в телефоне). Код запускается после скачивания проекта на компьютер путем запуска в терминале текстового редактора (VS Code в мое случае) сервера командой go run main.go.  Ардрес в браузере при после запуска сервера указывается как http://localhost:7540

## Инструкция по запуску:
1. В Branches выбрать **variant2**
2. Скачать архив через **Dowland ZIP**
4. Открыть скачанный репозиторий через редактор.
5. Ввести команды:
   >`go test .`
   >
   >`go run main.go`
6. Открыть в браузере ссылку http://localhost:7540


## Технологии:
* Go 1.21
* REST API
* Docker
